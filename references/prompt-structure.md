# 图片提示词结构

把提示词写成可检查的视觉规格，不堆砌形容词。推荐顺序：环境 → 主体 → 动作 → 镜头 → 光线 → 构图 → 风格 → 色彩/材质 → 画幅 → 约束。

## 核心字段

| 字段 | 内容 |
|---|---|
| `environment` | 时间、地点、背景层次和氛围 |
| `subject` | 人物、产品或核心物体 |
| `action` | 正在发生的明确动作 |
| `camera` | 景别、视角、焦段感和镜头运动暗示 |
| `lighting` | 光源方向、软硬、对比和情绪 |
| `composition` | 主体位置、前中后景、留白和视觉焦点 |
| `style` | 摄影、插画、3D 或图文卡片等媒介 |
| `palette` | 品牌色、辅助色和禁用色 |
| `materials` | 产品表面、服装、皮肤和环境纹理 |
| `aspect_ratio` | `16:9`、`9:16`、`1:1` 或 `4:5` |

## 参考图角色

每张输入图只能使用明确角色：`edit_target`、`identity_reference`、`product_reference`、`composition_reference` 或 `style_reference`。同一图片可以有多个角色，但必须逐项说明。

## 文字策略

- 1–6 个字的短标题可以要求逐字生成，同时保留人工检查。
- 长标题、价格、日期、二维码、参数表和品牌标准字使用 `text_overlay`，提示词要求“无文字、无水印、保留标题安全区”。
- 后期排版说明应包含原文、字体气质、位置、字号层级、颜色和对齐方式。

## 负面约束

只写与任务相关的失败模式，例如：多余手指、人物身份漂移、服装变化、产品按钮增减、包装文字乱码、标识变形、裁断主体、遮挡标题安全区、无关水印和竞争品牌。
